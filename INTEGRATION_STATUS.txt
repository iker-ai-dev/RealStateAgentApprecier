RetailScope AI — proposed integration, not a production deployment

Preserves the partner's chat-left / preview-right layout and existing property tabs.
Adds explicit Nimble MCP search for a chosen public market or a nationwide growth query.
Search runs only on the user's button click. No automatic or background searches.
Search snippets remain discovery evidence; they never update financial inputs automatically.

Known financial limitations:
The legacy cap/comparison/10-year DCF calculations remain illustrative heuristics.
Rent derived from household income and sales-price/SF is not a measured market rent.
Recoveries, operating expenses, immediate rent uplift, lease-up factors and valuation
weights remain unsupported assumptions. Physical vacancy no longer subtracts twice
from occupied lease rent. Complete rent-roll area reconciliation is still missing in demo data.
No dated equity cash-flow engine, debt schedule, verified T12 or executed leases is supplied.
Therefore this version ALWAYS reports Needs diligence; no target fit or purchase recommendation.

AI contract:
Cortex is restricted to bounded structured topic routing. The host renders the answer
from supplied facts and diligence flags; free-form LLM financial claims are not accepted.
STRIP_CENTER_AGENT_PROMPT.txt is the proposed future research-agent specification;
it is NOT a claim that the complete source-ledger/returns engine is implemented today.
Missing/unavailable/malformed Cortex output produces a visibly labeled deterministic fallback.
Model configuration ships blank; no provider call is made until the hackathon-provided
Cortex model is explicitly configured. Personal AI API keys are not used or required.
Model availability and live Cortex routing in the target Snowflake account are unverified.

The default Find deals route now filters seven source-backed public review leads,
with price/occupancy/source/income controls and a separate listing diligence view.
Unknown active status, occupancy basis, master leases, owner delivery, historical
availability and capital/demand risks remain explicit. This is not confirmed active
inventory. County context is historical and separate from trade-area evidence.
Public search is manual and bounded; search directories/reports do not count as
property candidates. No financial facts are inferred from search snippets.
