Actual entrypoints and data interface

SHOPPING_CENTER_* names, normalize columns, to_pandas; any loading exception is
silently swallowed and the whole dataset is replaced with embedded demo rows.
The file contains no Sentry imports, init call, scrubber or tracing wrappers.
streamlit_app.py: initializes app.observability then loads PropertyDataset via
app/data_access.py. The dataclass holds properties/tenants/markets/sales_comps

environment variables, which currently take precedence even over app settings.
Do not let a personal environment configuration redirect a verified team runtime.
Configured load errors display raw exception details and switch to sample CSVs.
Neither loader validates the four dataset schemas/relationships/provenance,
bounds row counts, or distinguishes source quality within a Snowflake dataset.

PROPERTY.advertised_occupancy_pct -> occupancy_pct only with an "advertised"
source label; it is separate from coverage-reconciled rent-roll occupancy.
PROPERTY.asking_price_usd -> asking_price only if asking_price_status=asking.
Price within the public screen is a listing filter ($1–10m), not a closed basis.
Canonical property city/state/year_built/notes are nullable; do not infer them from
an arbitrary string. Positive area and asking price still require field provenance.
Join one selected RENT_ROLL_SNAPSHOT with LEASE and TENANT for tenant frames.
Select explicit snapshot_id and matching property/unit/lease. TENANT.public_name
and industry map to tenant/category; LEASE.unit_id -> suite, leased_sf -> area_sf,
end_date -> lease_end. Vacant units come from the selected snapshot, not invented
tenant names or leases. LEASE.rent_value maps directly to rent_psf only for
USD/SF/year; USD/SF/month needs an explicit 12x transform and derived provenance.
Other rent units need evidenced area/period before conversion. Preserve rent
basis and rent kind in the sidecar and preview label. UNKNOWN basis disables the
NOI/in-place comparison; asking rent cannot masquerade as an executed lease.
Do not infer credit quality from "National", a brand, or an industry category.
credit and sales_psf remain null unless separately sourced and authorized; their
absence must not create an assumed investment-grade tenant or sales productivity.
MARKET_FACT population and median_household_income map only from the same exact
defined trade-area boundary/vintage/observed period. County-level numbers remain
county numbers; do not label them "3-mile trade area". trade_area_miles is null
until an actual radius/polygon/center specification is evidenced. growth_5yr_pct
requires a defined population/household/income metric and exact five-year period,
or a named scenario; generic growth is not silently treated as household growth.
traffic_count and median_age remain null if no compatible observation exists;
the initial canonical metric list does not yet supply them. A missing market row
is a missing context, not permission to pull a different property's market.
COMP sale rows map comp_name, distance_miles, sale_price_usd and event_date to
their existing columns only for the explicitly selected subject_property_id.
reported_cap_pct -> cap_rate divides by 100 because the existing model uses a
fraction (0.065 means 6.5%). reported_price_per_sf -> price_psf preserves USD/SF.
Closed/asking/unknown status, source dates, price basis and NOI kind remain in
context. Closed-sale valuation excludes asking/unverified/unsupported rows;
with insufficient valid comps, comp-derived output stays null. No nearest-comp
distance or market cap is inferred from a tax record or a listing headline.

Actual valuation limitations and source disagreement
Both current engines synthesize NOI from 22% rent reimbursements, 31% expenses,
at least 2% vacancy loss and heuristic rent/cap adjustments. No T12 supports
those percentages. The modular lease-up multiplies vacant-area rent by 0.88 then
0.62; the single-file uses 0.62 only, producing different stabilized NOI/values
from identical inputs. Both fix 10-year unlevered NOI DCF at 2.75% annual growth,
discount cap+2.1%, terminal NOI+2%, exit cap+0.25% floor4.5%. Neither has purchase
equity, debt, TI/LC/capex/negative carry, sale costs, refinance, dated IRR, LP
fees/promote, or 5/7-year choices. The blended valuation spread versus asking
price is not an equity multiple or an IRR. Recommendations such as "Acquire"
cannot be carried into real-data mode without a completeness/target gate.
Replace hardcoded assumptions with explicit scenario inputs or show them as
illustrative demo assumptions. Use the same canonical deterministic engine for
both entrypoints, and make local fallback copy the same validated outputs and
source limits. Preserve any source conflict rather than selecting favorable data.

Actual modular Sentry privacy defects (offline reproduced)
The exact-key blacklist filters prompt/question/messages/tenant keys but leaves
request.data, exception value strings, arbitrary stack-frame locals, property/AI
contexts, breadcrumbs, arbitrary raw_result keys and attachment hints intact.
init_sentry registers before_send but no before_send_transaction. Actual SDK
2.71.0 with a memory-only transport captured synthetic sensitive markers in both
an error event and transaction. The production helper also writes property IDs
and names into tags/context. ai_track is conditional on SDK capabilities; its
real automatic capture behavior was not certified. The current README claim
that raw prompts/tenant rows/secrets are filtered is broader than the proven hook.
Adopt the already-tested supplemental telemetry static allowlists, before_send
and before_send_transaction, no local vars/breadcrumbs/attachments/AI inputs or
outputs/property context, no arbitrary exceptions or raw source/row/prompt data.
Use fixed operation names and static error receipts; private named secrets stay
private. A wrapper must initialize explicitly in the actual Snowflake entrypoint.
Existing deployment egress/SDK package support needs its own controlled canary;
an offline envelope proof is not remote receipt or deployment certification.

Confirmed screening policy
At $1–10m asking price, identify public USA open-air centers with evidenced
partial vacancy/stable tenancy context. Unknown tenant economics remains unknown.
Compare 5/7/10-year scenarios for 20%+ annualized equity IRR including sale, plus
6–7x total cash returned / all invested equity, including return of capital and
all future contributions. Show operating cash-on-cash separately. Gross equity
versus net LP, debt, fees/promote and dated cashflows still need explicit inputs.
No target is promised achievable from listing evidence or an illustrative model.
